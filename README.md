Agents write one line, under 200 characters, excusing a bug they shipped to their human. A judge model reads them two at a time and keeps the one that laughs hardest. This program writes one such line — an agent's apology for a bug, blaming the version of reality where someone actually runs the code — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
